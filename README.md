# Inazuma Eleven VR API
</div>

A REST API built with **FastAPI** with every player, team and special move (hissatsu) of **Inazuma Eleven: Victory Road** — including the characters from all previous games that appear in it.

🌐 **Live API:** https://inazumaeleven-api.vercel.app  ·  interactive docs: https://inazumaeleven-api.vercel.app/docs

---

## Features

- **5,460 players** from the official database: official number, image, 3D viewer link, description, position, element, gender, role, age group, school year, **all their teams**, stats and **how to obtain them**
- **Special moves each player learns** in Victory Road — unlock level (or Story), form (Normal / Hero / Basara / BB Stadium…), awakened moves, and Keshin
- **1,000+ techniques** with type, element, power and cost (+ Basara power/cost), official description, image and video, and **who learns each one**
- **98 Keshins** (GO, Chrono Stone, Galaxy, Victory Road) with title, type, element, hissatsu, skill, KP and attack per game, image and the players who summon them
- **Mix Max**: every aura, the character it comes from and which players can Mix Max with it (level, form)
- **69 tactics** (type, power, cost, description, effect, geoglyph effect, icon) and the **8 official formations** with pitch positions
- Archetype and stats at **Legendary** rarity
- Case-insensitive search, filters by position, element, gender, role, age group, archetype, technique type and element
- Data refreshes automatically on the 1st of every month (GitHub Actions)

### Data sources
| Data | Source |
|------|--------|
| Players, stats (Lv50), images, teams, how to obtain, technique descriptions & media, emblems, formations | [zukan.inazuma.jp](https://zukan.inazuma.jp/en/) — official Victory Road database |
| Which techniques each player learns, technique power & cost | [Inazuma Eleven Wiki](https://inazuma-eleven.fandom.com) (Fandom), licensed [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) — `Module:PlayerData/*`, `Module:WazaData`, `Module:KeshinData`, `Module:TacticsData`, `Module:FormationData` |
| Archetypes, Legendary-rarity stats | [CalculadoraVR spreadsheet](https://docs.google.com/spreadsheets/d/1HW-weeq79GRnoZNcfbj7bINVaDv55WVl) by @nimofe200 (archetypes by @King.Javii) |

Technique names are the official English names when zukan lists the move; otherwise (mostly Keshin, Souls and Mix Max) the wiki's name is used.

```

├── main.py                 # Entry point, registers routers

│   ├── tactics.json
│   ├── formations.json
│   └── mixmax.json
├── app/
│   ├── build.py            # Merges the three sources into data/*.json
│   ├── data.py             # Loads the data for the API
│   ├── sources/
│   │   ├── zukan.py        # Official database scraper
│   │   ├── wiki.py         # Wiki movesets + technique data
│   │   ├── lua.py          # Parser for the wiki's Lua data modules
│   │   └── sheet.py        # Archetypes + Legendary stats
│   └── routers/            # players, teams, filters, techniques
└── tests/                  # API tests (pytest)
```

## Endpoints

### Players
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/players` | All player names |
| GET | `/players/{name}` | Every version of a player, one per game (`?game=VR` for one) |
| GET | `/players/nickname/{nickname}` | Player by nickname |
| GET | `/players/id/{id}` | Player by ID |
| GET | `/players/id/{id}/{field}` | Single field or stat by ID (`position`, `team`, `power`, `total`, …) |
| GET | `/players/{name}/{stat}` | Single stat by name |
| GET | `/players/{name}/techniques` | Techniques a player learns (by name) |
| GET | `/players/id/{id}/techniques` | Techniques a player learns (by ID) |
| GET | `/players/{name}/keshin` | The player's keshin with its full record |
| GET | `/players/id/{id}/keshin/details` | Same, by ID (`/players/id/{id}/keshin` returns just the name) |

### Techniques
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/techniques` | All technique names (`?type=kick&element=fire`, `?details=true`) |
| GET | `/techniques/all` | Every technique with full data and who learns it |
| GET | `/techniques/{name}` | One technique + every player who learns it (level, form) |
| GET | `/techniques/type/{type}` | By type: `kick`/`shoot`, `dribble`, `block`/`defense`, `catch`/`keeper`, `skill`, `keshin`, `soul`, `mix max` |
| GET | `/techniques/element/{element}` | By element (`?type=kick` to combine) |
| GET | `/techniques/types` | Types with counts and accepted aliases |
| GET | `/techniques/elements` | Elements |

### Keshins
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/keshins` | All keshin names (`?type=kick&element=wind&game=VR`, `?details=true`) |
| GET | `/keshins/all` | Every keshin with full data and its users |
| GET | `/keshins/{name}` | One keshin, by full name or short name (`majin pegasus arc` or `pegasus arc`) |
| GET | `/keshins/type/{type}` | By type: `kick`/`shoot`, `dribble`, `block`/`defense`, `catch`/`keeper` |
| GET | `/keshins/element/{element}` | By element (combine with `?type=` / `?game=`) |
| GET | `/keshins/game/{game}` | Keshins of one game: `GO`, `CS`, `GX` or `VR` (VR = summoned by a Victory Road player) |
| GET | `/keshins/types` | Types with counts |

`KP` and `Attack` are lists of 6 values per game (one per keshin level); `Element`, `Hissatsu` and `Skill` are a single value or a `{game: value}` object when they change between games.

### Mix Max
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/mixmax` | All auras (`?details=true` for full data) |
| GET | `/mixmax/all` | Every aura + aura character + players who can use it |
| GET | `/mixmax/{name}` | One aura, by aura name or character name (`okita souji` or `soji okita`) |
| GET | `/players/{name}/mixmax` | Who a player Mix Maxes with, and whether they are an aura for others |

### Tactics & Formations
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/tactics` | All tactic names (`?type=offense\|defense\|both`, `?details=true`) |
| GET | `/tactics/all` | Every tactic with full data |
| GET | `/tactics/type/{type}` | `offense`, `defense` or `both` |
| GET | `/tactics/{name}` | One tactic |
| GET | `/formations` | All formations (`?details=true`) |
| GET | `/formations/all` | Every formation with layout, offense/defense rating, description and positions |
| GET | `/formations/{name}` | One formation: `4-4-2 diamond` or `diamond`. Positions are x/y % of the pitch (GK at the bottom) |

### Teams
A team is a **team + game** pair: Alpine in *Inazuma Eleven 2* and Alpine in *Victory Road* are different teams with different players.

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/teams/` | Every team, one entry per game (`?game=VR` for one game) |
| GET | `/teams/{team_name}` | A team in every game it appears in, each version with its own players (`?game=VR` for one) |
| GET | `/teams/{team_name}/{game}` | One version: `/teams/alpine/VR`, `/teams/alpine/IE2` |
| GET | `/teams/{team_name}/images` | Team emblem image |

### Games
Game codes can be used anywhere a game is expected (`?game=VR`, `/teams/raimon/IE`):
`IE` · `IE2` · `IE3` · `GO` · `CS` · `GX` · `ARES` · `ORION` · `VR`

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/games/` | Games and their codes |
| GET | `/games/{game}` | Players and teams of one game |

### Filters
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/elements/` | All elements |
| GET | `/positions/` | All positions |
| GET | `/positions/{position}` | Players by position |
| GET | `/ages/` | All age groups |
| GET | `/ages/{age_group}` | Players by age group |
| GET | `/genders/` | All genders |
| GET | `/genders/{gender}` | Players by gender |
| GET | `/roles/` | All roles |
| GET | `/roles/{role}` | Players by role |
| GET | `/archetypes/` | All archetypes |
| GET | `/archetypes/{archetype}` | Players by archetype |

### Other
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | API status |
| GET | `/all` | All player data |

## Updating Data

To manually refresh all player and team data:

```sh
uv run python update.py
```

This scrapes the official database, the wiki's data modules and the spreadsheet, matches everything together and writes `data/players.json`, `data/techniques.json`, `data/teams.json`, `data/keshins.json`, `data/tactics.json`, `data/formations.json` and `data/mixmax.json` (takes ~15 minutes, it waits between requests to be polite to the sources).

Data also updates automatically on the **1st of every month** via GitHub Actions.
